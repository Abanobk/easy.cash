## تم استلامه (2026-09-13) — ميزان المراجعة PDF

- PDF «كل العملاء» + PDF «العملاء ذات الارصدة الصفرية» → تم تطبيق سلوك الصفوف في Easy.
- ميزان «تجميع فئة عملاء»: ميجا يطلب فئة؛ التينانت الحالي لا يستخدم الفئات — **مش مطلوب PDF**. Easy يطلب الفئة إجبارياً مثل ميجا.

# المطلوب من ميجا كاش لإكمال المطابقة

مرجع تصميم/تشغيل فقط — **لا نستورد بيانات الشركة**. Easy يشتغل على بيانات كل تينانت.

---

## 1) كشف حساب — فلاتر لسه معلّقة (أولوية عالية)

**منين:** تقارير الحسابات → **كشف حساب**

### أ) لقطة شاشة للفلاتر كاملة
- نفس شاشة الفلاتر قبل «عرض» تظهر فيها كل الحقول:
  - نوع القيد
  - اعتمد بواسطة
  - ملاحظات
  - الحساب المقابل (إن ظهر)
  - الـ 3 اختيارات: عرض حركات الرصيد الافتتاحي · عرض الحسابات المقابلة · اخفاء التفاصيل

### ب) سلوك كل اختيار (مهم جداً)
لكل اختيار من الثلاثة، اعمل **عرض** بنفس الحساب والفترة، وصدّر إكسل أو PDF، وسمّي الملف بوضوح:

| الملف المطلوب | ماذا تغيّر قبل العرض |
|---------------|----------------------|
| `as-default.xlsx` أو PDF | بدون تفعيل أي اختيار إضافي |
| `as-opening-movements.xlsx` | فعّل فقط «عرض حركات الرصيد الافتتاحي» |
| `as-counter-accounts.xlsx` | فعّل فقط «عرض الحسابات المقابلة» |
| `as-hide-details.xlsx` | فعّل فقط «اخفاء التفاصيل» |

ولو تقدر: سطر واحد تحت كل ملف يشرح «إيه اللي اتغيّر في الشبكة» (أعمدة زيادة؟ صفوف اختفت؟ …).

### ج) نوع القيد / اعتمد بواسطة
- لقطة لقائمة **نوع القيد** مفتوحة (كل القيم الظاهرة)
- لقطة لقائمة **اعتمد بواسطة** مفتوحة
- مثال واحد: اختَر قيمة من كل قائمة → عرض → إكسل، وسمّيه `as-entrytype-….xlsx`

---

## 2) ميزان المراجعة — طريقة تجميع العملاء

**منين:** التقارير النهائية → **ميزان المراجعة**

✅ تم من PDF: **كل العملاء** و **العملاء ذات الارصدة الصفرية**.

✅ **تجميع فئة عملاء**: ميجا يطلب إدخال فئة؛ التينانت الحالي لا يستخدم الفئات — مش هنطلب PDF. في Easy الخيار ده بيظهر حقل فئة إجبارياً قبل العرض.

---

## 3) موجة تانية — مبيعات / مشتريات / مخازن (إكسل بعد عرض)

لكل تقرير تحت: اختَر فترة فيها حركة → **عرض** → **تصدير لإكسل** (+ PDF لو ظهر زي كشف الحساب).

### مبيعات / مشتريات (الأهم أولاً)
| تقرير ميجا | اسم ملف مقترح |
|------------|----------------|
| تقرير المبيعات | `sales.xlsx` (+ PDF لو فيه) |
| تقرير المشتريات | `purchases.xlsx` |
| مبيعات العملاء | `customers-sales.xlsx` |
| مشتريات الموردين | `vendors-purchases.xlsx` |
| مجمل مبيعات العملاء بالأصناف | `gross-customer-sales-by-items.xlsx` |
| مجمل مشتريات الموردين بالأصناف | `gross-vendor-purchases-by-items.xlsx` |

### مخازن
| تقرير ميجا | اسم ملف مقترح |
|------------|----------------|
| ملخص المخزون | `inventory-summary.xlsx` |
| ملخص الأصناف / قائمة الأصناف | `items-summary.xlsx` |
| وارد وصادر صنف (لو غير حركة الأصناف اللي عندنا) | `item-in-out.xlsx` |

مع كل ملف: **لقطة فلاتر** قبل العرض (حتى لو سريعة).

---

## 4) PDF لتقارير تانية (اختياري بس مفيد)

لو تقرير بيفتح **عارض PDF** زي كشف الحساب (مش بس إكسل):
- حمّل الـ PDF + لقطة من العارض
- ده يخلينا نطابق الطباعة/الإرسال بنفس أسلوب ميجا

حالياً في Easy: كشف الحساب + ميزان + أستاذ ليهم طباعة رسمية؛ باقي التقارير لسه جدول عام.
