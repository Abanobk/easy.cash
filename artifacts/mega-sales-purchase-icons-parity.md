# مطابقة أيقونات فواتير البيع والشراء (Mega → Easy)

## المرجع (Mega Cash — لقطات الشريط الجانبي)

### فواتير الشراء
| Mega | Easy path |
|------|-----------|
| طلب شراء | `/purchases/orders/new` |
| قائمة طلبات الشراء | `/purchases/orders` |
| فاتورة شراء | `/purchases/invoices/new` |
| قائمة فواتير الشراء | `/purchases/invoices` |
| فاتورة مردود شراء | `/purchases/returns/new` |
| قائمة فواتير مردود شراء | `/purchases/returns` |

### فواتير المبيعات
| Mega | Easy path |
|------|-----------|
| طلب بيع | `/sales/orders/new` |
| قائمة طلبات البيع | `/sales/orders` |
| فاتورة مبيعات نقدية | `/sales/invoices/new?mode=cash` |
| فاتورة بيع | `/sales/invoices/new` |
| قائمة فواتير البيع | `/sales/invoices` |
| فاتورة مردود بيع | `/sales/returns/new` |
| قائمة فواتير مردود بيع | `/sales/returns` |

## السلوك
- أيقونة الإنشاء في ميجا = شاشة/نموذج منفصل عن القائمة → Easy يستخدم `/…/new` (نفس فكرة `/items/new`).
- القائمة تبقى على المسار الأساسي بدون `new`.
- عند الحفظ/الإلغاء من مسار الإنشاء يتم الرجوع للقائمة.
- تمييز العنصر النشط في الشريط الجانبي يفصل القائمة عن `/new` ويفصل فاتورة نقدية (`mode=cash`) عن فاتورة البيع.

## إضافات Easy (متعمدة — ليست في ميجا تحت هذين المجلدين)
- استيراد البيانات وغيرها تبقى تحت الإعدادات/المخازن كما هي؛ لم تُحذف ولم تُنقل تحت فواتير البيع/الشراء.


## سحب/إدخال المخزن عند إنشاء الفاتورة (مرجع Mega حي: `/Sales/Invoice.aspx` · `/Sales/Invoice.aspx/Cash` · `/Purchases/Receipt.aspx`)

### Mega
- أزرار منفصلة: **حفظ** و **اعتماد** (ليست «حفظ واعتماد» فقط).
- حفظ = مسودة (`المستندات المعلقة`) بدون أثر مخزني/محاسبي ظاهر حتى الاعتماد.
- اعتماد = التأثير على العميل/المورد والمخزن والخزينة وتكلفة المبيعات.
- مخزن على مستوى السطر + «الكمية المتاحة»؛ طباعة إذن المخزن مع الفاتورة.
- أصناف «وحدة خدمية» لا تؤثر على المخازن (موقع ميجا + نوع الصنف).

### Easy (بعد المطابقة)
- **حفظ** (`approveNow: false`) → دائماً `draft` بدون حركة مخزن وبدون قيود.
- **اعتماد** (`approveNow: true`) → سحب/إدخال مخزن + قيود (وبعدها الحالة paid/confirmed/partial).
- الأصناف الخدمية تُتخطى في حركة المخزن.
- المخزن إلزامي للأصناف المخزنية عند الاعتماد (لا سقوط صامت لأول مخزن).

### خارج النطاق الحالي (متعمد)
- تسليم مرحلي لاحق بعد الاعتماد (تسجيل تسليم إضافي لنفس الفاتورة) — الكمية المسلَّمة تُحدَّد عند الاعتماد؛ موجة لاحقة لـ `deliverMore`.
- تفجير طقم/مكونات عند البيع.
- تنبيه-أو-منع نقص الكمية كخاصية عامة قابلة للتبديل (حالياً المنع عند النقص).
