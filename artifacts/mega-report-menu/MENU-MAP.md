## كيف يشتغل تقرير ميجا (نمط موحّد)

1. من القائمة الجانبية **التقارير** → مجموعة → تقرير.
2. شاشة فلاتر (فرع / عملة / تواريخ / أطراف / خيارات عرض).
3. زر **عرض** يفتح النتيجة في عارض (`ifViewer`) — غالباً شبكة أو PDF.
4. تصدير إكسل / طباعة من شريط العارض.

أتمتة headless غالباً توصل للفورم وتضغط عرض، والعارض يفضل فاضي → لسه محتاجين إكسل/PDF من ميجا لأعمدة بعض التقارير.
