# كشف حساب عميل بالأصناف — مرجع ميجا

**المصدر:** PDF `كشف-حساب-عميل-بالاصناف.pdf` + لقطات الفلاتر (2026-09-13)  
مرجع تصميم/تشغيل فقط — Easy يعرض بيانات التينانت.

## الفلاتر (من الشاشة)

- الفرع
- العملة
- فئة العميل / المورد
- العميل (مطلوب في المثال)
- من تاريخ / الى تاريخ
- ☐ عرض تفاصيل الخصم
- ☐ اخفاء حسابات الطبيعة المزدوجة

أزرار: عرض · تصدير لاكسل · تفريغ

## أعمدة PDF (من اليمين لليسار منطقياً)

| حقل Easy | تسمية ميجا |
|----------|------------|
| `date` | تاريخ |
| `documentNumber` | رقم المستند |
| `description` | الوصف |
| `outQty` / `outPrice` / `outTotal` | صادر: كمية / سعر / اجمالي |
| `inQty` / `inPrice` / `inTotal` | وارد: كمية / سعر / اجمالي |
| `cashBankIn` | استلام نقدية / ايداع بنكي |
| `cashBankOut` | صرف نقدية / سحب بنكي |
| `checkCollected` | شيك محصل / تحت التحصيل |
| `checkRejected` | شيك مرفوض |
| `otherOps` | عمليات اخرى |
| `balance` | رصيد |

## صفوف خاصة

1. **الرصيد السابق** — رصيد أول المدة فقط
2. حركات الفترة (بنود فواتير في «صادر»، تحصيلات في أعمدة النقدية/البنك/الشيك…)
3. **اجمالي حركات الفترة**

## ملاحظات سلوك

- فاتورة مبيعات ترفع الرصيد (صادر)
- استلام نقدية / ايداع بنكي يخفض الرصيد
- عنوان PDF: «كشف حساب عميل بالاصناف فى الفترة من … الى … للعملة …»
